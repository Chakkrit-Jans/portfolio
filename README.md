## 🕹️ วิธีเล่น

| ปุ่ม | การกระทำ |
|---|---|
| `◀` `▶` หรือ `A` `D` | เดินซ้าย / ขวา |
| `Space` / `▲` / `W` | กระโดด — กดซ้ำกลางอากาศเพื่อ double jump |
| ปุ่มสัมผัสมุมจอ | สำหรับมือถือ / แท็บเล็ต |

- **✦ orb ทอง** = ทักษะ เดินชนเพื่อเก็บ
- **👾 monster ม่วง** = อุปสรรค กระโดดเหยียบเพื่อชิงประสบการณ์ (ชนด้านข้างจะกระเด็น แต่ไม่มีตาย — เส้นทางนี้ล้มแล้วลุกเสมอ)
- **📜 ใบรับรอง** = ไอเทมหายากบนแท่นสูง ต้องปีนแท่นแล้ว double jump
- ป้ายเขียว 🎓 = สถานศึกษา · ป้ายน้ำเงิน 💼 = สถานที่ทำงาน · ⚡ = ช่วงเรียนควบคู่ทำงาน

## 🛠️ เทคโนโลยี

Vanilla JavaScript + HTML5 Canvas — ไม่มี dependency, ไม่มี build step
รองรับเดสก์ท็อปและมือถือ, เสียงเอฟเฟกต์ผ่าน WebAudio

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเกม, HUD, overlay, ปุ่มสัมผัส |
| `data.js` | ข้อมูลไทม์ไลน์ 12 ด่าน, 48 ทักษะ, 5 ใบเซอร์ |
| `game.js` | เกมเอนจิน: ฟิสิกส์, ฉากหลังตามประเภทสถานที่, entity ต่างๆ |
